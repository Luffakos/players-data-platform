# Players Data Platform
End-to-end data engineering project on football/basketball player statistics (1992-2025).
Status: in progress (Day 1 of 60).
## Data source
Kaggle dataset "Dataset All_Players_1992-2025" by rodyanez:
https://www.kaggle.com/datasets/rodyanez/dataset-all-players-1992-2025
The raw data is NOT included in this repository (see .gitignore). Download it from Kaggle
and place the CSV in data/raw/.
